🔌 MCP Setup Guide

Connect your AI assistant to your Vault using the command below.

1 Create an access key:

Signed in as {{AUTH_USER}}. Create a key under Setup → Access Keys — it is shown once, so copy it then. The dashboard login itself is not a credential for an MCP client.

2 Paste the key into your client:

Run this in your terminal, replacing the placeholder with the key you just created:

claude mcp add --transport http memory-vault {{MCP_URL}} --header "Authorization: Bearer {{PSK_PREFIX}}<your-access-key>"

Other clients take the same key as a config-file header — see Setup for a ready-made snippet, per-client instructions and troubleshooting.
