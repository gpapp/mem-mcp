🚀 Local Proxy Bridge (Alternative: stdio transport)

If you prefer a stdio connection instead of SSE, you can use a local Node.js bridge script.

  1. ⬇️ Download mcp-bridge.mjs
    The downloaded file is already pre-configured with your secure credentials and server URL.
  2. Install dependencies in the folder where you saved the script:
    npm init -y
npm install @modelcontextprotocol/sdk
  3. Connect Claude Code to your local bridge:
    claude mcp add memory-vault-local node mcp-bridge.mjs
